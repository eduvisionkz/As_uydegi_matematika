ФАЙЛ
index.html — сайттың бүкіл мазмұны бір файлда (шрифттер, суреттер, есептер ішінде).
Интернетсіз де ашылады.

КАК ОПУБЛИКОВАТЬ
1) Netlify Drop (быстрее всего, без регистрации кода):
   откройте app.netlify.com/drop и перетащите папку As_uydegi_matematika.
   Сайт получит ссылку вида https://....netlify.app
2) GitHub Pages:
   создайте репозиторий, загрузите index.html,
   Settings → Pages → Branch: main → Save. Через 1–2 минуты появится ссылка.
3) Флешка / интерактивная доска:
   скопируйте index.html и откройте двойным щелчком в браузере.

ВАЖНО
- Фото, заметки, избранное и план дастархана хранятся только в браузере
  того устройства, где их ввели. На опубликованном сайте у каждого
  посетителя свои данные.
- Чтобы перенести свои данные: «Альбом» → «Сақтық көшірме» (резервная копия)
  или «Қосымшаны фотолармен сақтау» (HTML-файл с фото для флешки).
- На обложках — орнамент и буквы. Фото блюда можно поставить кнопкой «Суретке түсіру» на странице рецепта.
